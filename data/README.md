# WM-811K Dataset

## Dataset Overview

WaferWise AI will use the WM-811K wafer map dataset for semiconductor wafer defect classification research.

The dataset contains wafer maps collected from semiconductor manufacturing processes.

## Research Purpose

The dataset will be used to:

- Explore wafer defect patterns.
- Understand labelled and unlabelled samples.
- Study class imbalance.
- Train wafer defect classification models.
- Evaluate active learning strategies.
