# WaferWise AI

**AI-Based Semiconductor Wafer Defect Classification Using Active Learning**

## Overview

WaferWise AI is an independent research project exploring the use of machine learning and active learning for semiconductor wafer defect classification.

The project focuses on the WM-811K wafer map dataset and investigates how active learning can reduce manual annotation effort while maintaining classification performance.

## Research Objectives

- Explore and understand semiconductor wafer defect patterns.
- Perform exploratory data analysis on the WM-811K dataset.
- Develop a machine learning and deep learning approach for wafer defect classification.
- Investigate different active learning strategies.
- Compare model performance under different annotation budgets.

## Planned Experiments

The research will explore:

1. Random Sampling
2. Uncertainty Sampling
3. Diversity-Based Sampling
4. Hybrid Active Learning

Evaluation will focus on classification performance, macro-F1, rare-class recall and annotation efficiency.
